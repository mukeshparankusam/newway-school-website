- Newway Preschools

- Gallery section ready for gradual photo additions
- Admissions CTA ready for Google Forms + Google Sheets

## Before publishing
1. Create a GitHub repository.
2. Upload all files/folders from this project.
3. Replace `YOUR_GOOGLE_FORM_URL` in `index.html` with the final Google Form URL.
4. Replace `#` social links with official social URLs.
5. Add future gallery photos to `assets/` and update the gallery markup.
6. Enable GitHub Pages from the repository settings.
